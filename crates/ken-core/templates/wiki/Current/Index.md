# Current

Where does the project stand today? Each page says what's true now, and when that changes, someone rewrites it in place and never appends to it. Not here: what we chose to build and why → [[Design]]; a ruling → the decisions log; what was said in a meeting → [[Ingestion]].

## Belongs Here

A fact belongs here when a reader needs it as it stands today, and it goes stale unless someone rewrites it. When an ingested note or a commit changes what's true here, rewrite the page and cite it. A Roadmap or Feature Status page joins the table when it's first copied from `Templates/`. A change that lands or retires a feature updates its row on Feature Status in the same branch.
