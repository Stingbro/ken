# Tickets

Each piece of work gets one file here, `{{KEY}}-001.md`, copied from `Templates/Ticket.md`. The tickets are the work in flight and the work done: what was asked, the evidence, the wrong turns and how it ended. Nobody deletes a ticket, and a cancelled one says so in its status.

The library reads four keys from a ticket: `id`, `status`, `type` and `assignee`. On Ken's Log, an open ticket with an assignee is an action, and a ticket with `type: milestone` is a milestone, reached when it's done.
