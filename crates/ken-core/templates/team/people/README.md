# people/

One file per person. This is the roster — shared state, because `assignee` is a
core field and the board resolves against it.

```yaml
id: {{handle}}
name: {{Full Name}}
joined: {{date}}
```

Which of these you are is **local**, in your own Ken config, not here.

A self-selected identity is attribution by convention, not authentication.
That is fine — and the line is that no gate outcome may depend on it.
